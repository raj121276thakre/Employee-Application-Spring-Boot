# 👨‍💼 Employee CRUD API (Spring Boot)

A simple Spring Boot project that performs CRUD operations using an `ArrayList` instead of a database.

## 🔧 Functionality
- 🟢 **GET** all employees
- 🟢 **GET** Single employee
- 🟡 **POST** a new employee
- 🔵 **PUT** update existing employee
- 🔴 **DELETE** employee by ID

## 🔗 Endpoints

| Method | URL               | Description        |
|--------|-------------------|--------------------|
| GET    | `/employees`      | Fetch employees    |
| POST   | `/employees`      | Add employee       |
| PUT    | `/employees/{id}` | Update employee    |
| DELETE | `/employees/{id}` | Delete employee    |
